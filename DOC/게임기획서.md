## 게임 소개

「징검다리」는 가위바위보와 위치 이동 시스템을 결합한 1:1 캐주얼 전략 대전 게임이다. 두 플레이어는 10칸의 징검다리 정중앙(5번, 6번 칸)에서 마주 선 상태로 대결을 시작하며, 매 턴 선택한 가위바위보의 결과에 따라 상대방을 밀어내거나 뒤로 밀려나게 된다. 단순한 가위바위보의 확률 싸움을 넘어, 제한 구역 밖으로 상대를 밀어내어 낙하시키는 전략적 위치 선점과 예측 심리전이 핵심이다.



## 게임 기본 정보

* **게임 제목:** 징검다리

* **장르:** 캐주얼 전략

* **플레이 방식:** 1:1 턴제 대전 (Player vs Computer)

* **핵심 목표:** 가위바위보 승패를 이용해 상대 지우개 말을 징검다리 밖(10칸 제한 범위)으로 밀어내기

* **시작 위치:** 징검다리 정중앙 (영희 5번 칸, 철수 6번 칸)

* **조작 수단:** 마우스 클릭 및 키보드 단축키 (1: 가위, 2: 바위, 3: 보)



## 핵심 재미

* 어린 시절 책상 위 지우개 싸움과 징검다리 놀이의 감성을 현대적 캐주얼 게임으로 재해석.

* 매 턴의 승패가 연속적인 위치 변화로 누적되어 상대의 패턴을 읽고 수를 두는 즐거움 제공.

* C++ 난수 생성기 기반의 컴퓨터 선택에 맞춰 상황별 대응 방안을 판단하는 재미.

* 징검다리 끝으로 몰릴수록 높아지는 손에 땀을 쥐는 긴장감과 위치 선점 심리전.

* 결과에 따른 유쾌하고 감성적인 내기 승패 일러스트 연출.



## 게임 진행 흐름

1. 메인 메뉴(`SceneGameBegin`)에서 마우스 클릭으로 \[게임 시작\]을 선택한다.

2. 인게임(`SceneGamePlay`)이 시작되면 10칸 징검다리 중앙(5, 6번)에 영희(연분홍)와 철수(연하늘) 지우개 말이 마주 보고 배치된다.

3. 하단 UI의 \[가위\], \[바위\], \[보\] 버튼을 마우스로 클릭하거나 숫자키(1, 2, 3)를 입력해 카드를 제출한다.

4. 선택 완료 시 화면 중앙에 3 -> 2 -> 1 카운트다운 연출 후 C++ 난수 함수로 산출된 컴퓨터의 카드가 공개된다.

5. 가위바위보 승패를 판정하여 승리 시 1칸 전진(상대 말을 밀쳐냄), 패배 시 1칸 후퇴한다.

6. 무승부 시 두 말 모두 위치 변동 없이 다음 턴으로 진행된다.

7. 지우개 말이 징검다리 범위(1칸 미만 또는 10칸 초과)를 벗어나면 라운드가 즉시 종료된다.

8. 결과 화면(`SceneGameResult`)에서 최종 승자에 따른 일러스트가 출력되며, Enter 입력 시 게임 데이터를 초기화하고 메인 메뉴로 복귀한다.



## 규칙 및 시스템 명세

* **화면 해상도:** 800 × 600 (4:3 비율, glc2d 렌더링 기준)

* **징검다리 구성:** 일직선 상의 10칸 (X1 \~ X10), 양 끝 바깥은 낙하 구역

* **초기 배치:** 영희 지우개(X5), 철수 지우개(X6)

* **컴퓨터 패 결정:** C++ 난수 생성기( `rand()`)를 이용해 1\~3 (가위/바위/보) 균등 무작위 추첨

* **이동 규칙:** 영희 승리 시 오른쪽 1칸 이동, 패배 시 왼쪽 1칸 이동 (두 지우개 말은 하나의 묶음처럼 상대적 위치 유지하며 이동)

* **낙하(패배) 조건:** 말의 위치가 양 끝 바깥 진입 시 판정



## 화면 구성

* **MAIN MENU (`SceneGameBegin`):** 책상 위 도화지 배경, '징검다리' 캘리그라피 로고, \[게임 시작\], \[게임 방법\], \[나가기\] 버튼 표시

* **IN GAME (`SceneGamePlay`):** 클로즈업된 도화지 징검다리(10칸), 영희/철수 프로필, 지우개 말 배치, 하단 가위/바위/보 카드 버튼, 중앙 카운트다운 연출

* **RESULT (`SceneGameResult`):** 승리 연출(가방 메고 울상 짓는 철수) 및 패배 연출(아이스크림 사주는 영희) 일러스트, \[Enter\] 메뉴 이동 안내



## 객체지향 클래스 구조 설계

* `CApplication`: 메인 윈도우 생성, 프레임 루프 관리 및 씬(Scene) 전환 총괄

* `SceneGameBegin` / `SceneGamePlay` / `SceneGameResult`: 각 씬별 리소스 관리, 사용자 입력 처리, 게임 상태 제어 및 렌더링

* `Piece`: 징검다리 위 지우개 말 객체 (위치 인덱스, 좌표 연산, 이동 애니메이션 렌더링)

* `RPSManager`: 가위바위보 판정 매니저 (C++ 난수를 이용한 컴퓨터 선택값 생성, 플레이어 입력과 비교 연산 및 승패 산출)
